Section 01 // Strategic Objectives

2. วัตถุประสงค์การวิจัย (Research Objectives)

เป้าหมายเชิงวิศวกรรมเพื่อเพิ่มค่า Overall Equipment Effectiveness (OEE) และลดอัตราการหยุดเครื่องจักรโดยไม่คาดคิด

1. ลดเวลาการหยุดเครื่องจักร (Unplanned Downtime) -34% DOWNTIME

ติดตั้งเซนเซอร์ตรวจจับการสั่นสะเทือนและอุณหภูมิที่หัวเพลาขับ (Spindle) เพื่อทำนายการสึกหรอของคมตัดก่อนเกิดความเสียหายร้ายแรง

2. ควบคุมความเรียบผิวชิ้นงาน (Surface Roughness Ra) Ra ≤ 0.4 μm

ปรับเปลี่ยนอัตราการป้อน (Feed Rate) และความเร็วรอบแบบอัตโนมัติ (Closed-loop) เพื่อรักษาความเรียบผิวชิ้นงานให้อยู่ในเกณฑ์ไมโครมิเตอร์

3. ยกระดับอัตราส่วนงานผ่านครั้งเดียว (First Pass Yield) +8.5% FPY GAIN

เพิ่มอัตราส่วน First Pass Yield จากฐานเดิม 90.2% สู่ 98.7% โดยใช้โมเดลโครงข่ายประสาทเทียมแบบ Edge AI ประมวลผลที่ไลน์ผลิต

OEE TARGET LEVEL 92.4% World Class Benchmark
มาตรฐานอ้างอิง: ISO 22400 Operational Benchmark ระยะเวลาทดสอบ: 6 เดือน
Section 02 // Experimental Architecture

3. ตัวแปรต้น (Independent Variables)

ปัจจัยนำเข้าที่ถูกปรับเปลี่ยนอย่างเป็นระบบในชุดการทดลองเพื่อวิเคราะห์ผลกระทบต่อคุณภาพงานกลึง/กัดแม่นยำสูง

Param 01

Cutting Speed (Vc)

ความเร็วตัดของคมตัดชิ้นงาน ปรับทดสอบตั้งแต่ระดับความเร็วต่ำถึงสูงเพื่อสังเกตการสะสมความร้อน

RANGE: 180 - 320 m/min
Param 02

Feed Rate (fz)

อัตราการป้อนต่อฟันตัด ควบคุมด้วยเซอร์โวมอเตอร์ความละเอียดสูงเพื่อดูแรงกดตัดชิ้นงาน

RANGE: 0.05 - 0.20 mm/tooth
Param 03

Coolant Pressure

แรงดันน้ำยาคูลแรนต์ความดันสูง (High-Pressure Coolant) เพื่อการระบายความร้อนและกำจัดเศษตัด

RANGE: 20 - 70 Bar
Param 04

Sensor Sampling Rate

ความถี่ในการสุ่มเก็บข้อมูลแรงสั่นสะเทือน (Vibration) และกระแสไฟฟ้ามอเตอร์เข้าสู่ Edge AI

RANGE: 10 - 50 kHz
ตารางการทดลอง: Full Factorial Design of Experiments (DOE) 4 Factors / 3 Levels Array

5. ตัวแปรควบคุม (Control Variables)

สภาพแวดล้อมและสเปกวัสดุที่ต้องรักษาระดับอย่างเข้มงวดเพื่อป้องกันความคลาดเคลื่อนของการทดลอง

CTRL-01

วัสดุชิ้นงาน (Workpiece Material)

เหล็กกล้าผสม อลูมิเนียมเกรดการบิน (AL 7075-T6) ล็อตเดียวกันทั้งหมดเพื่อควบคุมความแข็งและโครงสร้างเกรน

Material Grade: AL 7075-T6
Hardness: 150 HBW ±2%
CTRL-02

สภาพแวดล้อม (Ambient Temp & RH)

ควบคุมอุณหภูมิและความชื้นสัมพัทธ์ในห้องปฏิบัติการเพื่อป้องกันการขยายตัวทางความร้อนของโครงสร้าง CNC

Ambient Temp: 20.0°C ±0.5°C
Relative Humidity: 50% RH ±4%
CTRL-03

คุณลักษณะมีดตัด (Tool Geometry)

ใช้ดอกกัดคาร์ไบด์เคลือบผิว TiAlN ใหม่มาตรฐานจากผู้ผลิตเดียวกันทุกการรันเพื่อขจัดผลจากการสึกหรอเริ่มต้น

Tool Type: Solid Carbide 4-Flute
Coating: PVD TiAlN 3μm
ข้อกำหนดควบคุม: ISO-9001 Calibration Certification Passed Variability Margin: < 0.3%

6. ขั้นตอนและระเบียบวิธีวิจัย (Methodology & Flowchart)

คลิกที่ปุ่มขั้นตอนหรือกดปุ่ม NEXT เพื่อดูเส้นทางและรายละเอียดการประมวลผลข้อมูล 5 ระยะ

RESEARCH PIPELINE TRAJECTORY STEP 1 OF 5: DATA INGESTION
PHASE 01 // DATA INGESTION

1. การรวบรวมข้อมูลเซนเซอร์ความเร็วสูง (High-Speed Data Ingestion)

Freq: 50 kHz

รับสัญญาณแรงสั่นสะเทือนแบบ 3 แกน (Tri-axial Vibration) และอุณหภูมิ Spindle ผ่านโปรโตคอล MQTT/OPC-UA ความเร็วสูงเข้าสู่บัฟเฟอร์ข้อมูล

Protocol: OPC-UA / MQTT
Sensor Type: IEPE Piezoelectric
Throughput: 1.2 GB/Hour
PHASE 02 // PREPROCESSING

2. การจัดเตรียมและกรองสัญญาณคลื่น (Signal Preprocessing & FFT)

Latency: 2.1ms

กรองสัญญาณรบกวนด้วย Wavelet Transform และแปลงข้อมูลจากโดเมนเวลาเข้าสู่โดเมนความถี่ (Fast Fourier Transform - FFT)

Filter Method: Continuous Wavelet
Noise Reduction: -18 dB Attenuation
Feature Dimension: 64 Time-Freq Features
PHASE 03 // MODEL TRAINING

3. การฝึกสอนโมเดลปัญญาประดิษฐ์ (Deep Neural Network Training)

Epochs: 200

ฝึกสอนสถาปัตยกรรม Hybrid 1D-CNN + LSTM เพื่อทำนายการสึกหรอของมีดตัดและความเรียบผิว Ra ล่วงหน้า 15 นาที

Model Arch: 1D-CNN + Bi-LSTM
Training Loss: 0.0014 MSE
Accuracy R2: 0.984 Score
PHASE 04 // EDGE DEPLOYMENT

4. การติดตั้งและประมวลผลที่ขอบเครือข่าย (Real-time Edge Deployment)

Inference: 8.4ms

แปลงโมเดลด้วย TensorRT เพื่อรันบนอุปกรณ์ Edge AI ที่ข้างเครื่องจักร CNC สำหรับส่งคำสั่งปรับแก้ Feed Rate แบบป้อนกลับ (Closed-loop)

Hardware: NVIDIA Jetson Orin
Optimization: INT8 Quantized
Control Loop: 100 Hz Feedback
PHASE 05 // VALIDATION

5. การตรวจสอบความถูกต้องและประเมินผล (Quality Validation)

Pass Rate: 99.6%

วัดขนาดและเกณฑ์ความราบเรียบด้วย CMM & Profilometer เพื่อยืนยันว่าผลลัพธ์ตรงกับเป้าหมายที่ตั้งไว้ในทุกสภาวะการตัด

CMM Precision: ±1.0 μm
Sample Status: Verified Passed
Yield Gain: +8.5% Net Gain
กดลูกศร ซ้าย-ขวา เพื่อเลื่อนขั้นตอน
Section 04 // Industrial Impact

7. ความสำคัญของการวิจัย (Significance & ECRS Framework)

การประยุกต์ใช้หลักการ ECRS ร่วมกับ AI เพื่อปรับปรุงสายการผลิตตามแนวคิด Lean Manufacturing

E - Eliminate (กำจัด)

กำจัดงานสุ่มตรวจด้วยมือ

ยกเลิกการหยุดเครื่องจักรเพื่อใช้ไมโครมิเตอร์วัดชิ้นงาน โดยเปลี่ยนเป็น AI ตรวจสอบอัตโนมัติ 100%

C - Combine (รวม)

รวมการวัดเข้ากับกระบวนการ

รวมกระบวนการเก็บข้อมูลแรงสั่นสะเทือนกับการประมวลผลทำนายการสึกหรอไว้ในเครื่อง CNC

R - Rearrange (จัดใหม่)

จัดลำดับการเปลี่ยนมีดตัด

เปลี่ยนจากการตั้งเวลาเปลี่ยนมีดตัดแบบคงที่ (Fixed schedule) เป็นการเปลี่ยนตามสภาพจริง (Condition-based)

S - Simplify (ทําให้ง่าย)

ทำให้การปรับแต่งง่ายลง

ใช้อัลกอริทึม Closed-loop ปรับอัตราการป้อนอัตโนมัติโดยผู้ควบคุมเครื่องไม่ต้องคาดเดา

ANNUAL COST SAVINGS (มูลค่าการประหยัด)

฿6,450,000

การลดลงของเศษชิ้นงานเสกน scrap และการยืดอายุการใช้งานดอกกัดคาร์ไบด์เพิ่มขึ้น 34% ต่อปี

ผ่านการรับรองคำนวณ ROI โดยวิศวกรโรงงาน
กรอบการทำงาน: ECRS Lean Manufacturing Protocol ผลตอบแทนการลงทุน ROI: 7.2 เดือน

Section 05 // System Evaluation & Risk

9. ข้อจำกัดและการวิเคราะห์ความเสี่ยง (Ishikawa Fishbone Risk)

แผนผังก้างปลาแสดงปัจจัยความเสี่ยงและแนวทางแก้ไข (Mitigation Strategies)

ISHIKAWA FISHBONE DIAGRAM (แผนผังก้างปลา) วิเคราะห์สาเหตุความคลาดเคลื่อน
PRIMARY RISK VECTOR

ข้อจำกัดของหน่วยความจำ Edge AI

การประมวลผลข้อมูลความถี่สูง 50 kHz บนบอร์ด Edge AI อาจพบข้อจำกัดเรื่องความร้อนและหน่วยความจำเมื่อรันต่อเนื่องเกิน 48 ชั่วโมง

กลยุทธ์การแก้ไข (Mitigation)

ใช้เทคนิค Model Quantization (INT8) และวงรอบการล้างข้อมูลบัฟเฟอร์แบบอัตโนมัติ ช่วยลดการใช้งาน RAM ลง 65%

สถานะความเสี่ยง: MITIGATED & CONTROLLED ระดับความเสี่ยงคงเหลือ: Low

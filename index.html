Early Experiments with GPT-4

Research Objectives

The primary goal of this research is to evaluate early, non-multimodal GPT-4 capabilities beyond traditional standard benchmarks to measure progress toward Artificial General Intelligence (AGI).

  • Cross-Domain Capability Analysis Probe holistic performance across mathematics, coding, vision (SVG/TikZ), law, medicine, and psychology.
  • Generative Rigor vs. Memorization Develop novel, hard interactive prompts to prove true cognitive reasoning over rote memorization.
  • Architectural Boundary Identification Uncover failure modes, hallucinations, and limitations inherent to purely autoregressive next-word prediction.

AGI Assessment Paradigm

Moving from narrow bench task benchmarks to psychological qualitative probing.

Target Paradigm: Qualitative & Generative Psychology Evaluation Model: GPT-4 (Early Release)

Methodology & Experimental Flowchart

Unlike conventional machine learning benchmarks prone to dataset contamination, the study employs a qualitative psychological probing approach.

1. Creative Synthesis Combine disparate fields (e.g. Math proof in Shakespeare poem).
2. Tool Interaction Ability to execute external Python code & parse feedback.
3. Spatial Mental Map Editing visuals (adding unicorn horn) without image sensors.
4. Fact Verification Detecting closed-domain vs open-domain hallucinations.

Significance of Research

Paradigm Shift in AI Paradigm

Proves that next-word autoregressive prediction on sufficient compute/scale yields emergent general capabilities beyond narrow task automation.

Interdisciplinary Integration

Demonstrates seamless cognitive fluency across code generation, medical diagnostic reasoning, legal analysis, and creative artistic synthesis.

Autonomous Tool Interaction

Shows GPT-4 can formulate strategies to query search engines, execute shell terminals, and self-correct calculation errors via external code runners.

Socio-Economic & Safety Impact

Establishes urgent need for safety guidelines regarding job displacement, misinformation generation, and alignment of super-human capabilities.

Weaknesses & Limitations

Despite general intelligence leaps, GPT-4 suffers from architectural limitations rooted in autoregressive next-token prediction without dedicated working memory planning.

Hallucinations

Generates plausible but false facts (e.g. placing McDonald's at SeaTac Gate C2 instead of Gate B).

Confident Misinformation
Lack of Planning

Cannot look ahead during output generation; fails complex mental arithmetic without step-by-step scratchpads.

Autoregressive Bottleneck
Arithmetic Errors

Makes simple calculation blunders in long equations unless coupled with Python code interpreters.

Numeric Reasoning Flaw
Discontinuous Memory

No continuous real-time learning post-training phase; updates only occur within context window session.

Static Model State
Critical Conclusion: GPT-4 requires human oversight or tool integration (e.g., Code Execution) for high-stakes clinical or mathematical deployments.

Research Summary & Conclusion

01

Early AGI Pioneer

GPT-4 can reasonably be viewed as an early (yet incomplete) AGI system, displaying human-level breadth and depth across varied domains.

02

Beyond Next-Word Prediction

Scaling transformer architectures creates emergent behaviors that transcend memorization, forming abstract cognitive representations.

Next Paradigm Needed

True general intelligence requires moving beyond autoregressive limitations to incorporate deliberate planning, working memory, and real-time learning.

Reflective Output

[ Critical Analysis ]

ข้อจำกัดและเส้นทางสู่อนาคต

แม้จะมีประกายแห่ง AGI แต่ GPT-4 ยังมีจุดอ่อนสำคัญที่ต้องได้รับการวิจัยและพัฒนาแก้ไขต่อไป

Hallucinations & Working Memory

ระบบยังเกิดอาการ "ภาพหลอน" (สร้างข้อมูลเท็จด้วยความมั่นใจ) และขาดความจำระยะยาว (Working Memory) ทำให้การแก้ปัญหาที่ต้องวางแผนระยะยาวหลายขั้นตอนยังมีข้อผิดพลาด

Lack of Continuous Learning

โมเดลเป็นแบบ Static ไม่สามารถเรียนรู้ข้อมูลใหม่ได้แบบ Real-time หลังจากจบกระบวนการ Pre-training ต้องพึ่งพาการป้อนข้อมูลใน Prompt Context
